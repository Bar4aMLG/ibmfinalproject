
# GreenLeaf Houseplants E-Commerce Website

This is a React + Redux e-commerce website for houseplants, built for the IBM course project. It features:

- Landing page with a welcoming message and background image
- Product listing page with six houseplants, grouped by category
- Shopping cart with add, remove, increase, decrease, and clear functionality
- Header with navigation and live cart count
- Responsive design using Bootstrap

## Live Demo

[View the website on GitHub Pages](https://Bar4aMLG.github.io/ibmfinalproject)

## Notes

- The main focus was on React, Redux, and functionality. CSS and visual polish were kept simple for clarity and time.
- Images are loaded lazily for better performance.
- All code is open source and available for review.

## How to Run Locally

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server
